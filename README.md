# Mini Blockchain (C++)

Учебная реализация блокчейна на C++. Проект повторяет ключевые механики
настоящих блокчейнов (Bitcoin) в упрощённом виде: криптографическое
хеширование, связывание блоков через хеши и Proof of Work (майнинг).

Это не сеть и не настоящая криптовалюта — всё работает в одной программе
на локальной машине. Цель проекта — разобраться, *как* блокчейн устроен
изнутри.

## Что умеет

- Хранит цепочку блоков, где каждый ссылается на хеш предыдущего
- Майнит блоки (Proof of Work): подбирает `nonce`, пока хеш не начнётся
  с нужного числа нулей
- Проверяет целостность цепочки и ловит подделку данных

## Как собрать и запустить

Требуется компилятор с поддержкой C++17.

```
g++ -std=c++17 -O2 src/main.cpp -o blockchain
./blockchain
```

## Зависимости

- [PicoSHA2](https://github.com/okdshin/PicoSHA2) — header-only реализация
  SHA-256 (MIT License), лежит в `src/picosha2.h`.

## Структура проекта

```
src/
  picosha2.h    — библиотека SHA-256
  block.h       — класс одного блока
  blockchain.h  — контейнер цепочки блоков
  main.cpp      — точка входа, демо-сценарий
```
